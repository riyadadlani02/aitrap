What the frames give away

Two functions in the same request disagree about what the customer spent. The tier discount sees the real subtotal; the coupon check is handed the figure after that discount came off, so a $628.49 cart is judged against $565.64 and told it hasn't reached $600. Shipping is fed the same wrong number, so free-delivery-over-$600 fails too.

The source reads fine — evaluate_promo(coupon, net_subtotal, items) is a plausible line. Only the runtime values show it is the wrong argument.
